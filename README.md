# Flappy Bird - Atividade Acadêmica (UEA)

Este repositório contém um projeto desenvolvido em **Godot 4** como parte da **Atividade 013: Aprendizado usando IA**.

O objetivo da atividade foi utilizar uma ferramenta de IA como apoio para aprender programação em Godot 4, desenvolvendo um jogo no estilo **Flappy Bird**. A proposta não foi apenas gerar o jogo automaticamente, mas estudar os conceitos usados no desenvolvimento, entender o código e conseguir apresentar o funcionamento do projeto.

## Sobre o jogo

O jogo segue a mecânica básica de Flappy Bird.

O jogador controla um pássaro que precisa se manter no ar e atravessar os espaços entre os obstáculos. A cada obstáculo ultrapassado, a pontuação aumenta. Se o jogador encostar nos canos ou cair na zona de morte do chão, a partida termina e a tela de Game Over é exibida.

O jogo também possui sistema de melhor pontuação, salvando o recorde localmente.

## Como executar o projeto

1. Clone ou baixe este repositório.

```bash
git clone https://github.com/by-amaral/flappy-bird-godot.git
```

2. Abra o **Godot 4**.

3. Clique em **Importar**.

4. Selecione o arquivo:

```text
project.godot
```

5. Abra o projeto.

6. Execute o jogo pelo botão de play do Godot.

## Controles

* **Clique esquerdo do mouse**: faz o pássaro bater as asas.
* **Botão Retry** na tela de Game Over: reinicia a partida.

## Funcionalidades implementadas

* Movimento do pássaro com clique do mouse.
* Gravidade aplicada ao personagem.
* Rotação do personagem durante subida e queda.
* Animação de flap.
* Sons de flap, colisão e pontuação.
* Obstáculos em movimento horizontal.
* Geração automática de obstáculos.
* Variação aleatória da altura dos obstáculos.
* Colisão com obstáculos.
* Zona de morte no chão.
* Sistema de pontuação.
* Sistema de melhor pontuação.
* Salvamento local do recorde.
* Tela de Game Over.
* Botão para reiniciar a partida.
* Organização em cenas e scripts separados.

## Relação com a atividade

A atividade solicitava o uso de IA para criar um plano de estudos e aprender a programar em Godot 4 desenvolvendo um jogo estilo Flappy Bird.

Mesmo utilizando poucas vezes a IA pois já tinha noção do que fazer devido a atividades anteriores, foi um ótimo aprendizado de programação e um lembrete o quão forte a IA é como ferramenta; mesmo utilizando o Claude Free, os 2-3 momentos que o utilizei para sanar dúvidas de leigo ele simplesmente "iluminou" minha mente e além de ajudar na resolução das dificuldades, ainda explicou robustamente como melhorar algumas coisas, otimizar, automações no geral, muito incrível...

Este projeto atende aos entregáveis principais:

* jogo funcionando;
* código-fonte disponível no GitHub;
* organização do projeto em cenas, scripts e assets;
* uso de IA como ferramenta de estudo;
* aplicação prática dos conceitos de programação em Godot 4.

## Observações

Este projeto foi desenvolvido com finalidade acadêmica.

A IA foi utilizada como ferramenta de apoio para estudo, explicação de conceitos, organização do plano de desenvolvimento e auxílio na compreensão do código. O objetivo principal foi aprender a lógica de programação em Godot 4 e conseguir explicar o funcionamento do jogo.
